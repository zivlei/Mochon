# מוחון – קובץ מרכזי לדירוגים ולסטטיסטיקות שימוש

הדירוגים והנתונים על המשחקים נשמרים ב-**Google Sheet** שלכם, דרך Google Apps Script. זה חינמי, ואין צורך בשרת.
הנתונים אנונימיים: האפליקציה שולחת רק קוד מכשיר אקראי, את שם המשחק, הרמה, הציון, הזמן והדירוג (1–5 כוכבים). שמות שחקנים לא נשלחים לעולם.

## הקמה (פעם אחת, כ-5 דקות)

1. פתחו את https://sheets.new ותנו לגיליון שם, למשל "מוחון – נתונים".
2. בתפריט: **תוספים ← Apps Script**.
3. מחקו את מה שכתוב שם, הדביקו את כל התוכן של הקובץ `apps-script.gs` מהתיקייה הזאת ולחצו 💾 שמירה.
4. לחצו **פריסה ← פריסה חדשה**:
   - סוג: **אפליקציית אינטרנט** (Web app).
   - "הפעלה בתור": **אני**.
   - "למי יש גישה": **כל אחד** (Anyone).
   - לחצו "פריסה" ואשרו את ההרשאות לחשבון שלכם.
5. העתיקו את **כתובת אפליקציית האינטרנט**. היא מסתיימת ב-`/exec`.
6. הדביקו את הכתובת בקובץ `js/cloud.js`, בשורה `const CLOUD_URL = "";`, ופרסמו גרסה חדשה (או שלחו לי את הכתובת ואני אעדכן).

## מה רואים בגיליון

- **plays** – שורה לכל משחק ששוחק: זמן, מכשיר, משחק, תחום, רמה, ציון, שניות, גרסה.
- **ratings** – שורה אחת לכל מכשיר ומשחק, עם הדירוג האחרון.
- **summary** – סיכום לכל משחק: ממוצע כוכבים, מספר דירוגים, כמה פעמים שוחק, ומכמה מכשירים שונים. הסיכום מתעדכן בכל פעם שהאפליקציה מבקשת אותו.

## עדכון הקוד בעתיד

אחרי שינוי ב-`apps-script.gs`: **פריסה ← ניהול פריסות ← ✏️ ← גרסה: חדשה ← פריסה**. הכתובת נשארת אותו דבר.
