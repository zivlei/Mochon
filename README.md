# מוחון 🧠

אימון יומי למוח לגיל השלישי – עובד בטלפון וב-iPad, גם בלי אינטרנט אחרי הכניסה הראשונה.

**לשחק:** https://zivlei.github.io/Mochon/

## מה יש
- **שחקנים** – כל אחד עם שם ותמונה; ההתקדמות נשמרת על המכשיר.
- **4 תחומים, 6 משחקים, 3 רמות קושי:**
  - 🧠 זיכרון – זוגות, רצף
  - 🔢 חשבון – תרגילים
  - 🎯 ריכוז – מצאו את השונה, מספרים לפי הסדר
  - ✋ קואורדינציה – בועות
- **ניקוד 0–100** לפי אופי המשחק (דיוק, מהירות, אורך רצף), נקודות מצטברות לפי רמה (×1 / ×1.5 / ×2).
- **משימות יומיות** – 3 משימות מתחומים שונים בכל יום, הראשונה תמיד מהתחום החלש.
- **התקדמות** – כללית ולפי תחום, מגמה וגרף של המשחקים האחרונים.

להוספה למסך הבית ב-iPad/iPhone: Safari ← שיתוף ← "הוסף למסך הבית".
